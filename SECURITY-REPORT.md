1. **"Dynamic code execution" in async**:

   - Standard practice in async flow control libraries

2. **"HTTP transport" in winston**:
   - This is an OPTIONAL transport for sending logs to HTTP endpoints
   - Not used unless explicitly configured
   - Legitimate feature for log aggregation services

3. **"Hex encoding" detections**:
   - These are color codes for terminal output (e.g., \x1b[31m for red)
   - Standard ANSI escape sequences, not obfuscation
