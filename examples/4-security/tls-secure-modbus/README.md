# Modbus TLS Security Examples for Node-RED

This directory contains Node-RED example flows for secure Modbus TCP communication using TLS/SSL encryption.

## 🔒 Overview

These example flows demonstrate:
- Secure Modbus TCP server with TLS encryption
- Secure Modbus TCP client with TLS authentication
- Certificate-based mutual authentication (mTLS)
- Real-time monitoring of secure connections

## 🚀 Quick Start in Node-RED

### Step 1: Import the Example Flows

These flows can be imported directly from Node-RED:

1. Open Node-RED in your browser
2. Go to **Menu (☰) → Import → Examples → node-red-contrib-modbus**
3. Select **"Modbus TLS Server Example"** or **"Modbus TLS Client Example"**
4. Click **Import**

Or manually import:
1. Go to **Menu (☰) → Import → Clipboard**
2. Copy contents of `modbus-tls-server-flow.json` or `modbus-tls-client-flow.json`
3. Paste and click **Import**

### Step 2: Generate TLS Certificates

Before deploying the flows, generate the required certificates:

```bash
# Navigate to the examples directory
cd ~/.node-red/node_modules/node-red-contrib-modbus/examples/tls-secure-modbus/certs

# Run the certificate generation script
./generate-certificates.sh
```

This creates test certificates for development:
- `ca-cert.pem` - Certificate Authority
- `server-cert.pem` & `server-key.pem` - Server certificate and key
- `client-cert.pem` & `client-key.pem` - Client certificate and key

### Step 3: Configure TLS in the Flows

#### For the Server Flow:
1. Double-click the **"Secure Modbus Server (TLS)"** node
2. Click the pencil icon next to **TLS Configuration**
3. Upload the certificates:
   - Certificate: `server-cert.pem`
   - Private Key: `server-key.pem`
   - CA Certificate: `ca-cert.pem`
4. Click **Update** and **Done**

#### For the Client Flow:
1. Double-click the **"Secure Modbus Client (TLS)"** node
2. Edit the Modbus client configuration
3. In TLS Configuration, upload:
   - Certificate: `client-cert.pem`
   - Private Key: `client-key.pem`
   - CA Certificate: `ca-cert.pem`
4. Set Server name to: `modbus-server`
5. Click **Update** and **Done**

### Step 4: Deploy and Test

1. Click **Deploy** to activate the flows
2. Watch the debug panel for connection status
3. The client will automatically read data from the server every 5 seconds
4. Use the inject nodes to trigger manual operations

## 📊 What the Examples Demonstrate

### Server Flow Features:
- TLS-encrypted Modbus TCP server on port 8502
- Simulated sensor data (temperature, humidity, pressure)
- Automatic data updates every 5 seconds
- Digital I/O simulation (coils)
- Connection status monitoring

### Client Flow Features:
- Secure connection to TLS Modbus server
- Reading holding registers with data parsing
- Writing control values
- Reading digital inputs (coils)
- Connection status with TLS indicator

## 🔐 Security Features

- **TLS 1.2+** encryption
- **Mutual authentication** (client and server certificates)
- **2048-bit RSA** keys
- Protection against **MITM attacks**
- **Encrypted** Modbus communication

## 🛠️ Troubleshooting

### Common Issues:

1. **"Certificate not found"**
   - Run the certificate generation script first
   - Check file paths in TLS configuration

2. **"Connection refused"**
   - Ensure server flow is deployed and running
   - Check port 8502 is not blocked

3. **"TLS handshake failed"**
   - Verify certificates are properly configured
   - Check server name matches certificate

### Enable Debug Output:
```bash
DEBUG=contribModbus* node-red
```

The certificates generated by the script are for **testing only**. For production:
- Use certificates from a trusted Certificate Authority
- Never commit private keys to version control
- Implement proper certificate rotation
